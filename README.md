# 🍃 Caderno de Receitas

Um espaço para reunir, descobrir e compartilhar receitas de diferentes tipos, valorizando a culinária e a experiência de cozinhar.

## 📖 Sobre o projeto

O Caderno de Receitas é meu primeiro projeto autoral de desenvolvimento web, criado para colocar em prática meus conhecimentos de HTML e CSS e evoluir gradualmente como desenvolvedora.

A proposta é construir um site de receitas com uma interface agradável, navegação simples e conteúdo organizado, unindo aprendizado, criatividade e culinária.

## 🎯 Objetivos

- Praticar a estruturação de páginas com HTML.
- Desenvolver uma interface com CSS.
- Aprender a organizar arquivos e componentes de um projeto web.
- Construir um projeto próprio para meu portfólio.
- Evoluir o projeto gradualmente com novas funcionalidades.

## ✨ Funcionalidades planejadas

- Página inicial com apresentação e receitas em destaque.
- Catálogo de receitas organizado por categorias.
- Páginas com ingredientes, tempo de preparo, rendimento e modo de preparo.
- Página sobre o projeto.
- Página de contato.
- Layout adaptável para diferentes tamanhos de tela.

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript — planejado para uma etapa futura.

## 🚧 Status do projeto

Em desenvolvimento.

Este projeto será construído por etapas, começando pela estrutura das páginas e pelo design visual. Novas funcionalidades serão adicionadas conforme meu aprendizado avançar.
